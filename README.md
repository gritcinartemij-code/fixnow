# FixNow — Online MVP

## Что это
FixNow — MVP сервиса поиска мастеров по ремонту: клиент создаёт заявку, прикладывает фото, выбирает мастера, общается с ним и отслеживает статус. Есть роли клиента, мастера и администратора, PWA и базовая админ-панель.

## Локальный запуск
1. Установите Node.js 20+
2. Откройте терминал в папке проекта
3. Выполните `npm start`
4. Откройте `http://localhost:3000`

## Онлайн-тест
Проект подготовлен для Render Web Service. Render запускает Node.js web service через команду `npm start`, а health check настроен на `/api/health`. Render выдаёт публичный `onrender.com` адрес.

### Важно до реальных пользователей
Сейчас данные и фотографии хранятся локально в файловой системе приложения. Для настоящего сервиса нужно перенести данные в PostgreSQL, фотографии — в объектное хранилище, сделать полноценную авторизацию, секреты, резервное копирование, модерацию, юридические документы и уведомления. Бесплатный Render следует использовать только для тестирования.
